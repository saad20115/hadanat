# وحدة إدارة اشتراكات الحضانات ورياض الأطفال — Aureus ERP
## Nursery & Kindergarten Subscription Management Plugin

وحدة متكاملة ومخصصة لإدارة اشتراكات ومتابعة أطفال الحضانات ورياض الأطفال مبنية لنواة **Aureus ERP** (Laravel 13 + FilamentPHP 5 + PostgreSQL + TailwindCSS 4).

---

## 🌟 المميزات الرئيسية (Core Features)

1. **Zero Cognitive Load Intake (نموذج التسجيل الذكي السريع):**
   - احتساب الفئة العمرية للطفل تلقائياً بمجرد إدخال تاريخ الميلاد.
   - فلترة باقات الأسعار المتاحة حسب الفئة العمرية المحددة للطفل فقط.
   - احتساب تاريخ نهاية الاشتراك تلقائياً حسب نوع المدة (ساعات / يومي / أسبوعي / شهري / فصلي / سنوي / باقات زيارات).
   - تطبيق خصم الإخوة الآلي (5%) للاشتراكات الشهرية والفصلية عند تسجيل أكثر من طفل لنفس ولي الأمر.
   - إضافة التيشيرت الرسمي (75 ر.س) بضغطة زر.
   - سداد كامل أو دفعات أولى مرنة مع إيصال دفع فوري PDF.

2. **محرك دورة الحياة وحساب الحالات (Lifecycle Engine):**
   - الحالات: `جديد (NEW)` ← `ساري (ACTIVE)` ← `ينتهي قريباً (EXPIRING_SOON)` ← `منتهي (EXPIRED)` ← `تم التجديد (RENEWED)` ← `ملغي (CANCELLED)` ← `مجمّد (FROZEN)`.
   - أمر يومي مجدول عبر Cron: `php artisan nursery:update-statuses`.

3. **التجديد بنقرة واحدة (One-Click Renewal):**
   - زر تجديد سريع ينشئ اشتراكاً جديداً يبدأ مباشرة في اليوم التالي لانتهاء الاشتراك السابق بنفس الباقة والمواصفات.

4. **لوحة متابعة تشغيلية (Operational Dashboard Widgets):**
   - إحصائيات سريعة بالأطفال والاشتراكات السارية والمنتهية.
   - جدول الاشتراكات التي تنتهي خلال 7 أيام للتواصل السريع مع أولياء الأمور.
   - جدول المبالغ المتبقية مع زر تسجيل دفعة سريعة.

5. **دعم كامل لـ PostgreSQL:**
   - استعلامات محايدة لقواعد البيانات متوافقة بنسبة 100% مع PostgreSQL 14/15/16.

## 🚀 التثبيت والتشغيل المحلي (Local Installation)

```bash
# 1. تثبيت الحزم
composer install

# 2. تشغيل الهجرات والـ Seeders
php artisan migrate
php artisan db:seed --class="Webkul\\NurserySubscription\\Database\\Seeders\\PricingPlanSeeder"

# 3. تشغيل السيرفر
php artisan serve
```

## ☁️ الرفع على هوستنجر VPS مع PostgreSQL (Hostinger VPS Deployment)

### الطريقة الأولى: السكربت الآلي بنقرة واحدة (Automated One-Click)
```bash
# داخل السيرفر VPS (Ubuntu 22.04 / 24.04):
chmod +x deploy-hostinger.sh
./deploy-hostinger.sh
```

### الطريقة الثانية: عبر Docker Compose مع PostgreSQL 16
```bash
# تشغيل الحاويات (App + PostgreSQL 16 + Redis)
docker compose -f docker-compose.pgsql.yml up -d --build
```
